## Lessons captured today
- A step name with an unquoted ": " breaks the whole CI silently (Kai). Rule: run a YAML parse on every PR; quote names that contain ": ".
- Capture command exit codes under set -e (Kai). Rule: `|| rc=$?`, print the output, then exit.
- A new optional contract field must degrade its own section, not blank the screen (Leo, Theo). Rule: test absent versus malformed separately.
- Do not disable git hooks (Leo). One commit used core.hooksPath=/dev/null. Proposal for TEAM §5: never disable hooks; PR body states hook and check status for each commit.
