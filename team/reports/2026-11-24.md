## Lessons captured today
- **Lead:** shared scratch file names collided once (one PR body repaired): use unique names. Give reviewers the decision status. Do not post for an agent whose action was denied; surface it. A cause stated in a status needs the logs first (the Appium diagnosis was wrong until the Pi journal arrived). Stop a stale duplicate agent before it posts. When a decision changes a timing constant, grep `.github` and docs for the old value before assigning.
- **Team:** a health check on `/status` cannot catch a slow session start: split errors by phase. Test every guard on its cap and overflow path (bash arithmetic wraps). When a firmware value is pinned in CI or bench docs, require the companion change before approval. A new wait belongs in a small script with a fail-closed cap and an offline test.
