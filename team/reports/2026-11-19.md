## Lessons captured today
- A fix merged into another PR's branch after that PR reached main is NOT on main: check `git merge-base --is-ancestor <commit> origin/main` before saying "merged" (Lead/Sana; 4.B2c path guard, earlier 4.A9 #117).
- A validation of retained state must cover every index/bound member of the struct, not only the first (Theo/Mira, #140).
- A guard on the destructive path must fail open for cleanup and loud for reporting (Theo/Leo, #139).
- Mutate the UI layer as well as the service; a field only the screen uses stays unguarded (Ines, #139).
- Gate a slow CI job on a narrower path set and add it to Final status needs in the same commit (Kai, #138).
- Build claim-checks from CI run numbers, not PR bodies (67+62 vs 66+61) (Poppy).
- Showcase captions follow the public-text rule too (no PR numbers, task IDs, first names) (Theo, #137/#140).
