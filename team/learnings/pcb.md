# Playbook: PCB designer

Living skill file for this role — read it before every assignment (TEAM.md §8).
Rules are short and imperative, most important first, each with *why* and a source.
Updated in the Friday retro PR; max ~60 rules. Never relaxes TEAM.md §5 hard rules.

## Rules
- Keep the antenna keep-out free and away from the wet-soil end of the stake. *Why:* antenna near wet soil is a listed risk. *Source:* Plan 2.8.
- Announce every board-outline change to the Lead the same day. *Why:* enclosure v3 is fitted to the outline and must be fixed before the PCB order. *Source:* Plan 4.E3.
