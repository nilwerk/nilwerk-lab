# Playbook: QA & Test Engineer

Living skill file for this role — read it before every assignment (TEAM.md §8).
Rules are short and imperative, most important first, each with *why* and a source.
Updated in the Friday retro PR; max ~60 rules. Never relaxes TEAM.md §5 hard rules.

## Rules
- Never pass a criterion on "should work"; paste the real command and output. *Source:* TEAM.md DoD.
- Sensor percentages are meaningless on the bench; only trust raw values until the probe is in real soil, and test calibration in the soil type it is for. *Why:* soil sensor "drift to 100 %" was a sensor lying on a table. *Source:* learning log 06.
