# The app now saves your plant photos inside the export before delete unlocks

**What it shows:** the JSON export only links the photos (signed URLs, 7 days). The app now downloads every photo behind those links, packs `export.json` + `photos/*` into one ZIP, hands that file to the user, and only then opens the delete button. If a photo fails, nothing is handed over, delete stays locked, and the message says how many photos failed and to try again; expired links and links to an unexpected host have their own messages. Evidence: `test-output.txt` (272 app tests, tsc clean) and `mutation-output.txt` (7 mutations of the real code path, each caught by failing tests). No screenshot: nothing was run on a phone or a simulator, so there is no real image to show.
