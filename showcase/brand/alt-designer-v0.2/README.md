# Alternative v0.2 "designer" (PROPOSAL, for comparison with v0.1)

Arsany's feedback: v0.1 looks "so AI-like"; wants a more modern designer touch, more Nilwerk-specific, logo simpler, **not a rework**. So this folder is an alternative that sits next to v0.1. Nothing in v0.1 (`../brand-kit.md`, `../brand.css`, `../templates`, `../logo`, `../previews`, the posts and images in `showcase/content/2026-11-07/`) was edited or deleted. He decides later which one to adopt.

**Start here:** `comparison-board.png` (v0.1 vs v0.2, posts 1 and 2 at Instagram and LinkedIn size, and the logo options) and `logo/logo-options-sheet.png`.

## What changed and why (5 points)

1. **Cards, pills and chips removed.** v0.1 used soft rounded tiles with equal padding, a pill kicker and a boxed status chip: the generic "AI template" look. v0.2 uses a strict grid (72 px margins, 8 px step), hairline rules, plain mono labels and one small square marker for the caveat. White space does the grouping.
2. **One typographic statement, the number as hero.** Headline in Space Grotesk 500 (lighter, larger, tighter) instead of bold; the proof number is set very large in JetBrains Mono 600 (458 mA, a giant 0) and the secondary number small. Real data is the visual; no decoration.
3. **The PCB trace is the one graphic device, tied to the content.** Post 1: a trace from a pad runs across the page and through one resistor zigzag labelled R9, off the edge. Post 2: lane A runs on through its own rows ("A's own rows: allowed"); a branch of A bends toward lane B and stops at the dashed per-row wall ("B's rows", marked with a cross) while B runs on. Post 1's zigzag is labelled illustrative: R9 is the charger's PROG-pin resistor, not a series element. Accent green is used only for the trace, the hero label and the mono "FOR ENGINEERS" label; amber only for the caveat.
4. **Simpler logo, three options (A recommended).** A: one single-weight trace-N line plus one pad ring, no plate, no wave, lowercase wordmark with tighter tracking (accent on the pad only). B: wordmark with the pad as the i-dot. C: wordmark with a trace line underneath. Variants for A: mono (one colour), reverse on ink, circle-crop avatar and a heavier-stroke favicon that holds at 16 px. The v0.1 logo file is untouched and shown beside them.
5. **Same system underneath.** Same palette family (tokens renamed identically, plus `--nw-rule`), same fonts (Space Grotesk, Inter, JetBrains Mono, all Google Fonts, OFL), same two-layer logic (plain story first, FOR ENGINEERS block second), same texts, caveats and claim-check. AA contrast is checked on `brand-alt.css`: `python3 -I check_contrast.py` (exit 0). Used pairs: ink/bg 16.19 (light), muted/bg 5.67, accent/bg 4.83, warn/bg 4.52 (light, small mono labels, just above the limit), all dark pairs 7.2 or higher; rule lines are decorative.

Known trade-offs: JetBrains Mono's default zero has a dot inside, which reads techy and large "0" looks odd to some non-technical readers (option: set the hero in Space Grotesk instead); the lighter headline weight needs the 1080 px size and is weaker at small preview size; the trace needs per-post drawing (two functions in `build_alt.py`, one per motif).

## Files

| File | What |
|---|---|
| `brand-alt.css` | tokens, same names as `../brand.css` plus `--nw-rule` |
| `check_contrast.py` | AA checker (reads `brand-alt.css`, or a css path argument) |
| `templates/` | portrait 1080x1350, LinkedIn 1200x627, square 1080x1080, generated by `make_templates.py` |
| `build_alt.py` | fills templates, trace helpers, renders PNG; `--previews previews` renders placeholder previews (light and dark) |
| `logo/` | option A lockup, mono, reverse, mark, avatar, favicon; B and C wordmarks; `logo-options-sheet` (svg and png); made by `make_logos.py` (wordmarks are outlined to paths with fontTools, no font needed; the wordmark has no kerning table applied) |
| `previews/` | the three templates with placeholder text, light and dark |
| `make_board.py` / `comparison-board.png` | the A/B board |
| `../../content/2026-11-07/alt/` | posts 1 and 2 re-rendered in v0.2 (6 PNG + SVG), `build_alt_images.py` reads the texts from `../build_images.py` |

Rebuild everything: `export NW_FONT_DIR=<node_modules>/@fontsource` (from `npm i @fontsource/space-grotesk @fontsource/inter @fontsource/jetbrains-mono`), then `python3 -I make_templates.py && python3.13 -I make_logos.py` (make_logos.py needs a Python with fontTools, e.g. a python3.13 venv with `pip install fonttools`; the other scripts run on plain python3) ` && python3 -I build_alt.py --previews previews && python3 -I ../../content/2026-11-07/alt/build_alt_images.py && python3 -I make_board.py`.

## How to switch to v0.2 (if Arsany chooses it)

1. Tokens: use `brand-alt.css` in place of `../brand.css` (same variable names; pages keep working).
2. Templates and build: use `templates/` and `build_alt.py` for new posts instead of `../templates` and `../build_post.py`; each post then supplies `TRACE` (a trace motif tied to its content) and fills `HERO_*` / `AUX_*` (the proof number and the secondary number).
3. Logo: pick A, B or C from `logo/`; A's `alt-a-avatar.svg` and `alt-a-favicon.svg` are the profile picture and favicon. nilwerk.de itself still shows the v0.1 logo until the website is changed (not part of this task).
4. Content: the images in `showcase/content/2026-11-07/alt/` replace those in `images/`; texts, alt texts and claim-check stay valid.
5. Then `brand-kit.md` is updated to v0.2 (section 2 logo, section 3 palette use, section 8 templates) and v0.1 files are moved to an `archive/` folder by a human-approved PR. Until the decision, v0.1 stays the working version for drafts.

## Font dependency note

The logo SVGs in `logo/` are outlined. The **template and post SVGs** (v0.2 here, and v0.1 in `../templates` and `showcase/content/2026-11-07/images`) still reference Space Grotesk, Inter and JetBrains Mono by name, so they need those fonts installed to look right in Figma, Canva or Inkscape; the PNGs are the deliverable for posting. Not changed in v0.1.
