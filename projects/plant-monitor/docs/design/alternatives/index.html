Plant Monitor: three design directions

Three ways to make the simple app feel modern. Each direction shows three screens: My plants, the setup progress, and the done screen. The copy is the app's current copy, so the only change is the look and the layout. Nothing here is copied from another product; the ideas come from general principles in the app design review (P1–P9). Each direction is a sketch, not a final design: colours are placeholders, and each change must be made in tokens.json and regenerated.

Status: draft for Arsany's choice. Poppy checks any copy changes against the claim rules before they ship.

What changes in every direction

Bench and tests: the bench reads labels from strings/en.json at run time, so any change to a label, a step order or a key needs a bench check on hardware (Peter) and a test update (Ines). Direction A changes the order of the setup progress and the main button on My plants, so it needs the most bench work. Direction B changes only layout and colour, so it needs the least. Direction C changes colour and text emphasis, and its contrast must be re-checked with the 4.5:1 rule in theme.test.ts.

Sketch only. Icons, illustrations and the final type scale are not included.
