# PCB
- Schematic review: ERC zero errors; strapping pins and pull-ups checked against the pin map.
- Part gate: LCSC part number, lifecycle (active / NRND / EOL), stock and price at 3 pcs and 1k pcs.
- Simulation gate: each sim script has pass/fail limits; plots attached.
- Layout gate: the fab's DFM rules are loaded as KiCad design rules; DRC zero errors; antenna keep-out checked. Run DRC after each layout block, not only before review.
- Output gate: Gerber, drill, BOM and CPL generated by script; CPL rotation checked against the footprint.
- Handoff: evidence for gate G4a in the PR; Arsany places any order (agents never order).
- Shop access (LCSC, JLCPCB) requested at project start, so stock is not "unverified" late.

## Reference designs and sourcing (from the pcb-design agent definition)
- Before designing a circuit block from scratch, search vendor reference designs and open projects (published schematic, PCB source, BOM, licence, test evidence). Compare against our actual battery, regulator, connector and mechanical limits. Reuse a verified block; never copy a whole design blindly. If none fits, record what was searched.
- Part verification order: exact MPN and live orderability in the JLCPCB parts catalog first, then DigiKey and Conrad for the same part or a verified equivalent. Record MPN, distributor, stock and check date. Same function is not drop-in.
- A DigiKey or Conrad listing does not make a part JLCPCB-assemblable. Confirm JLCPCB can source it or take it as consigned; otherwise mark it hand-soldered or pick a JLCPCB-orderable part.
- ERC/DRC with zero errors is not proof the circuit works. Check critical pin mappings and power paths against the datasheet.
- Run KiCad tools on a working copy only. Autorouter completion is not layout verification: inspect pours, return paths, high-current loops, antenna keep-outs and pad connectivity. Refill zones after routing.
- ngspice only with usable vendor models; state what is not modelled. Without a model, do datasheet worst-case calculations and list the bench measurements needed. Never invent a pass/fail.
- The vendored `kicad`, `spice`, `emc`, `datasheets`, `bom`, `lcsc` and `jlcpcb` skills (see `skills/vendor/README.md`) cover these checks.

## Second-opinion checks (from the 14 Nov skills trial)
- Before each package, run `analyze_pcb --full`, `analyze_gerbers` and `fab_release_gate` from `skills/vendor/kicad` on a **copy**. Triage every finding as TRUE, FALSE POSITIVE or UNCLEAR with evidence. Never quote a heuristic finding as a verdict.
- Compare the Gerber outline size with the board outline before any order. A stale zip is a release blocker (found on 14 Nov: 67.05 mm vs 67.8 mm).
- Put an MPN in every schematic symbol field, and add board fiducials, or the release gate stays red.
