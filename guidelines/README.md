# Guidelines — how we build prototypes

- `guidelines/prototype/` — rules for every prototype (any product). Start with `README.md` there.
- `guidelines/by-role/` — one short file per role: what that agent must follow, drawn from the prototype rules and its playbook.
- `team/TEAM.md` stays the charter (hard rules, roles, time reporting). These guidelines never relax TEAM §5.
- `skills/` holds the online references. `skills/ROLE-MAP.md` says which agent reads which file.

Lifecycle: a rule enters here through a PR, reviewed by Theo (technical) and Ines (testable). Rules that are project-specific stay in `projects/<project>/`.
